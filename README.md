# 魔女語翻譯機

《魔法少女ノ魔女裁判》裡的魔女語（fiXmArge Language）與中文的雙向翻譯工具。

**網頁版**：https://jiajia729.github.io/-/

## 功能

- **中文 → 魔女語**、**魔女語 → 中文**雙向翻譯。
- **規則模式**：查官方詞庫並套用文法規則，輸入時自動翻譯，免費、離線也能用。
- **AI 模式**：遇到詞庫沒有的詞，會照英日疊合的構詞規則造新詞。可以用自己的 Anthropic API 金鑰（預設 Haiku，可切換 Sonnet）；放在 claude.ai 上時則直接使用 Claude 帳號。
- **防呆**：AI 標成「官方」的詞，程式會再對照詞庫檢查，查不到就改標為自創。
- **自創詞**：AI 造出的新詞會存在瀏覽器裡，之後翻譯沿用同一個拼法，也可以匯出。
- **詞庫瀏覽**：313 個詞，可以用魔女語、中文、日文或讀音搜尋。

每個翻譯出來的詞都會標示來源：官方詞（設定集）、歌詞推定、文法規則補上、自創／推測、查不到。

## 檔案

| 檔案 | 內容 |
|---|---|
| `dictionary.tsv` | 詞庫（魔女語、片假名、日文、中文、詞性、來源） |
| `GRAMMAR.md` | 文法筆記，標註每條規則的信心程度 |
| `src/engine.js` | 規則翻譯引擎 |
| `src/template.html` | 網頁介面 |
| `tools/build.py` | 把上面三者組成 `index.html` |
| `tests/engine.test.js` | 引擎測試 |

修改詞庫或程式後，執行：

```sh
python3 tools/build.py
node tests/engine.test.js
```

## API 金鑰

金鑰只存在你自己的瀏覽器（localStorage），翻譯時由瀏覽器直接送到 Anthropic，不經過其他伺服器。不要在公用電腦上儲存金鑰。

## 說明

詞彙整理自官方設定集的截圖（經由 NGA 玩家整理帖），文法則是從主題曲的對照歌詞推測而來，並非官方文法。本專案為同好非營利的學習交流用途，與官方無關。
